# Verilog

This is a git repository of Verilog codes for revisiting the basic concepts of Digital Electronics. This repository contains basic codes of Verilog. This will be a excellent source for revision of Digital Electronics

CODE FILES -
1) NOT GATE
2) AND GATE
3) OR GATE
4) XOR GATE
5) HALF ADDER
6) FULL ADDER
7) FOUR BIT FULL ADDER
8) FOUR BIT FULL ADDER/SUBTRACTOR
9) BCD ADDER
